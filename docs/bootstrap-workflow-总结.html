每周主题工作流 · 启动周

目标不是「多读一点」，而是每周用一个明确主题把自己拽完闭环：选题 → 吸收 → 双轨产出 → 上墙。

一、为什么要「每周一题」

  • 日更项目适合碎片输入；周主题适合形成可复用的判断框架。
  • 公开上墙制造轻微外部约束，减少半途而废。
  • 双轨产出强制区分「纪实理解」与「结构提炼」。

二、标准一周节奏

  • 周一：定主题 + 写一句话成功标准（本周结束时能回答什么）。
  • 周二至周四：主材料精读 / 实践，只收集能支撑结论的证据。
  • 周五：写 HTML 总结（叙事、证据、边界）。
  • 周末：画 SVG 知识图（关系、对比、行动清单）并发布。

三、双轨产物约定（对齐 video-notes）

  • {slug}-总结.html：可阅读的完整总结，偏纪实与推理过程。
  • {slug}-知识图.svg：可滚动长图，偏结构、边界与行动。
  • 在 docs/index.json 增加一条周条目，首页自动出现。

四、本周验收

  • 仓库骨架可用，本地能预览首页。
  • GitHub Pages 指向 docs/ 或 Actions 部署成功。
  • 下一周可以直接按模板追加主题，不必再搭脚手架。
