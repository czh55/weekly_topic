第 0 章 · 面向大模型的数学基础
精炼补丁，专门打初学者会认错的地方

学习留存 · 2026-10-17 · 本周只读第 0 章
原文：《大模型：从 Transformer 到部署》第 0 章（介金）
读法：选读章，也可当随查手册。通读大约 4–6 小时。后面打算每周一章。

这一章解决的核心问题是：只学过大学高数上册的人，缺哪几块数学，才会在后面 17 章的公式前停住。作者不铺全套教材，而是按依赖顺序补丁，并在每个符号第一次出现时把「最容易认错」标出来。

1. 为什么读起来脉络清楚

每节结构固定：直觉 → 形式定义 → 后文哪一章用到 → 可运行代码 → 延伸阅读。数学不再是孤立定义，而是「这个符号以后在第几章干什么」。

依赖顺序也写死了，不能跳着乱补：

  1. 0.1 先学会读符号
  2. 0.2 线性代数、0.3 概率
  3. 两者合起来才撑得住 0.4 信息论、0.5 微积分与矩阵求导
  4. 最后汇入 0.6 优化、0.7 数值表示

所以它既是字典，也是一张地图。后面读第 3 章注意力、第 12–13 章强化学习，卡住时可以退回对应小节，而不是重学一门课。

2. 初学者最容易认错的几处

醍醐灌顶的地方不在新公式，而在这些「同名不同义」和「名字很像但返回的东西不同」。

容易错成其实是为什么会害到后面
max 和 argmax 是一回事max 返回最高值，argmax 返回最高值在哪贪心解码要的是「哪个词」，不是「概率多大」
一句话的概率就该连乘几百个小于 1 的条件概率连乘会下溢到机器表示不了训练目标几乎总写成对数：乘变加，才既安全又好求导
同一个字母全书一个意思H 可以是熵、头数、隐藏维或 Hessian；L 是层数，花体 ℒ 才是损失看到字母先问：后面跟着的是分布，还是矩阵？
温度也写成 T本书温度统一记 τ，T 在第 1–2 章是序列长度和序列长度、训练时间、专家数撞车
交叉熵就是「模型有多差」交叉熵 = 数据本身的熵 + KL。熵与模型无关，降不下去最小化交叉熵等价于最小化 KL；Scaling Laws 里那个降不到的 E 就是这份熵
KL 两个方向差不多前向 KL 逼模型盖住真实分布每个角落；反向 KL 让模型缩到某个峰上RLHF 里 KL 约束的方向不是随便写的
困惑度和损失是两个指标PPL = exp(损失)，指数单调，所以是同一件事的两种刻度训练日志上的交叉熵和评测表里的 PPL 可以互译
训练主要怕掉进局部最优高维损失面上，鞍点远多于真正的坑100 亿个方向「恰好都朝上」才困得住；动量和自适应步长是为了穿过平台、对付梯度量级差几个数量级
FP16 和 BF16 都是「半精度，差不多」同样 16 位：FP16 范围窄（约 65504 就溢出），BF16 范围和 FP32 一样宽，但有效位更少混合精度要不要 loss scaling，取决于你选的是窄范围还是糙精度
softmax 就是 exp 再归一化必须先减去最大值。平移不变，但裸 exp 在 FP16 下 logits 到十几就会变成 inf注意力实现里这是必写的一行，不是优化技巧

矩阵乘法的形状规则单独记一条：内侧维度必须相等，(m×k)×(k×n)=(m×n)。报维度错误时先查这个。注意力里 QKᵀ 是 (n×d)×(d×n)，复杂度 O(n²d)——长上下文贵，贵在序列长度的平方，不是隐藏维。

3. 七块零件，各自通向哪一章

小节记住的一句后面用在
线性代数点积是相似度；词是高维空间里的一个点第 3 章注意力打分；CLIP 先把向量归一化再点积，得到的就是余弦相似度
概率一句话的概率 = 条件概率连乘：P(w₁…wₙ)=∏ P(wᵢ∣w<ᵢ)第 1 章语言模型定义；第 2 章训练与生成；相邻词不独立，这正是语言建模有意思的地方
信息论越意外信息量越大；交叉熵用「错误的分布」给真实数据编码训练目标 -log P(下一个词∣前文)；困惑度；RLHF 的 KL 约束
微积分梯度指向最陡上坡，训练沿负梯度下坡反向传播就是链式法则在计算图上连乘
softmax + 交叉熵梯度 = 预测概率 − one-hot。对了梯度为 0，错得越离谱梯度越大第 2 章输出层、第 3 章注意力权重、专家路由、策略分布，是同一个函数换了输入含义
优化一步更新来自一阶泰勒：往下降最多的方向是负梯度第 6 章 Adam ≈ 动量 + 逐参数自适应步长
数值浮点是二进制科学计数法，精度和范围此消彼长第 6 章混合精度，第 10、14 章量化

一条可带走的工作流：公式先手推，再用 autograd 或中心差分对答案。不确定 softmax 雅可比对不对时，用 (f(x+h)−f(x−h))/(2h) 验，而不是对着书再抄一遍。

4. 边界

  • 这一章不替代线代或概率课。特征值、大雅可比只要求直觉：矩阵有主方向，深度学习几乎从不显式求逆。
  • 它是选读。可以跳着当字典用；但作者建议通读一遍后再看第 3 章和第 12–13 章，会顺很多。
  • 符号以书后附录 A 为准。本章只排「同一字母撞车」的雷，不改附录。
  • 本周只读完第 0 章，没有做章末的手算、编程和 Scaling Laws 思考题。那些留到用到对应章时再验。

5. 后面怎么读

节奏改成每周一章。第 0 章的零件先停在这里。下一章不继续推公式，而是先画大语言模型的全景：它到底是什么，后面十几章各自在解决什么，再把这些零件装回去。

  1. 读第 1 章时，只核对链式法则和「词是一个点」是否还站得住。
  2. 读第 2 章时，亲手把「梯度 = 预测 − 标签」推一遍，并用数值梯度验收。
  3. 读第 3 章时，回到 O(n²d) 和 softmax 减 max，确认注意力实现没有裸写 exp。
  4. 符号拿不准，先回 0.1 的撞车清单，再查附录 A。
