1. 起点：一个真实的配时难题

一切从一个具体得不能再具体的路口说起。二通西路南口 plan1，三股车流、两个阶段：

车流（pair）S1 东西直行S2 西向通行
东-直行58.8·
西-直行 搭接48.548.5
西-左转·6.0

数字是归一化流量（用户数 ÷ log₂(车道数+1)）。西-直行是搭接车流：它在两个阶段都保持绿灯。配时引擎的现行做法是把它平分进两个阶段（÷stageCount），于是 S2 的权重被西-直行的「半份」48.5÷2 = 24.25 撑大——而它本来只需服务 6.0 的左转。引擎口径算出总权重 83.1。

但直觉告诉我们这里面有浪费：S1 被东-直行的 58.8 撑起来后，西-直行（只要 48.5）顺带就被放完了，S2 只需要留 6.0 给左转。如果这样安排，总权重只要 64.8。两个数字差 28%。

真正的问题不是「哪个方案好」，而是……

「我怎么证明 64.8 已经是最优，而不是 64.5 或 63？我怎么量化 83.1 浪费了多少、其他算法又各自浪费多少？」——这个问题把我们一路引向线性规划、凸性、对偶理论和一整套运筹学地图。本文就是这条路线的完整留存。

2. 什么是线性规划

2.1 名字拆解：线性 + 规划

「线性」指数学结构：目标函数和所有约束都是变量的一次式——变量只以一次方出现，没有乘积、没有平方、没有 sin/cos。任何一个出现，就不再是 LP。

「规划」（programming）是个历史误会的产物：1940 年代美军为「制定行动方案」发明的术语，与计算机编程无关——LP 的诞生（Dantzig，1947，单纯形法）比现代编程语言还早几年。同一个用法也留在「动态规划」（Dynamic Programming）这个名字里。

2.2 标准形式与三要素

min cTx
s.t.  Ax ≤ b,   x ≥ 0 目标线性 + 约束线性 + 变量非负

建模套路永远是三句话：

  • 变量 = 你能控制的东西；
  • 约束 = 世界的规则；
  • 目标 = 你想要的方向。

2.3 把配时问题翻译成 LP

对二通西路南口：变量是各阶段时长 t₁、t₂；规则是「车流只认绿灯总量够不够，不认在哪个阶段」；目标是总时长最短。

min  t₁ + t₂
s.t.  t₁ ≥ 58.8 （东直：只在 S1 放）
        t₁ + t₂ ≥ 48.5 （西直：两段都放，加起来够就行）
        t₂ ≥ 6.0 （西左：只在 S2 放）

注意 t₁ + t₂ ≥ 48.5 这条约束——它就是「西直可以蹭」的数学表达：S1 撑得够高，S2 完全不出力也行。LP 建模的全部艺术，就是把业务规则写成这种「加起来够就行」的等式/不等式。

3. LP 通常解决什么问题

本质上是同一类问题的千变万化：有限资源，怎么分配，使收益最大 / 成本最小。

问题家族典型问题线性结构
生产计划工时/原料/机器台时有限，产几种产品，怎么排产利润最大变量=各产品产量，约束=资源上限
配比/混合油品调和、饲料配方（最早的「营养问题」）变量=各成分用量
运输/物流产地→仓库/门店的货运量分配，运费最小变量=各条线路运量
网络流最大流、管道/电网调度变量=各边流量
金融组合优化、现金流匹配变量=各类资产持仓
排班与调度人员排班、班次覆盖（连续松弛版）变量=各班次人数

配时归因也在这个家族里：每个阶段是一台「机器」，每股车流是要被满足的「订单」，搭接车流是「可以用两台机器合力完成」的订单。

为什么 LP 成了工程默认选项

不是世界真的线性，而是：① 线性模型在业务精度内「够用」；② 求解器极快极稳（百万变量级）；③ 凸性带来的一切保证（见第 5 节）。问题天生非线性，模型主动线性化——LP 的统治力来自工程上的「够用且可靠」。

4. 优化问题的分类地图：三根轴

「LP 的对立面是 NLP」对，但不完整。优化问题的分类有三根正交的轴：

轴1：函数形状    线性 ──── 非线性
轴2：变量类型    连续 ──── 整数/混合（IP / MIP）
轴3：可解性      凸   ──── 非凸      ← 这根轴在实践中最重要
类别目标/约束变量可解性典型问题
LP全线性连续凸生产计划、运输、配时下界
QP目标二次、约束线性连续凸（Hessian 半正定时）组合风险、SVM、最小二乘
SOCP线性+二阶锥约束连续凸机器人控制、鲁棒优化
凸 NLP任意凸函数连续凸几何规划
非凸 NLP有非凸项连续只有局部最优结构设计、化工流程、深度学习
IP / MIP线性+整数变量离散/混合NP-hard选址、排班、TSP
MINLP非线性+整数离散/混合最难档工艺综合设计
关键认知

实践中的真正分水岭不是线性/非线性，而是凸/非凸。凸的非线性规划（QP、SOCP）几乎和 LP 一样可靠；一旦非凸，再「简单」的问题也可能掉进局部最优。工程界口头禅：能写成凸的就别写成非凸的，能写成线性的就别写成非线性的。

家族谱系是一条链：LP ⊂ QP ⊂ SOCP ⊂ 凸NLP——每层放宽目标形状，但死守凸性底线（H = 0 时 QP 退化为 LP，所以 LP 是 QP 的特例）。

5. 凸与非凸：优化世界的地形学

5.1 碗与月球表面

把优化想象成扔一颗弹珠找碗底：

  • 凸：地形是一只碗。弹珠从任何位置放下，顺坡滚落，必然落进同一个碗底——全局最低点。
  • 非凸：山地，多个山坳、山脊、平台。弹珠从不同位置放下滚进不同的山坳——你找到的「最低点」可能只是附近最深的一个，隔壁山谷更深，但弹珠翻不过山脊。

5.2 线段测试：严格定义只要两句话

凸集（可行域的形状）：集合里任取两点，连线全程不出界。实心圆、矩形是凸的；月牙形、环形不是（连线会穿出界外）。

凸函数（目标函数的形状）：图像上任取两点，连线（弦）不低于函数本身：

f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y),  ∀λ ∈ [0,1] 图像在弦的下方——只许凹下去（碗），不许鼓起来（山丘）

x²、|x|、ex 是凸的；sin(x) 在整条数轴上不凸。一个优化问题是凸的 = 凸的目标函数 + 凸的可行域。

5.3 凸性为什么是「免死金牌」

核心定理：凸问题的任何局部最优就是全局最优。推论：

  1. 下降算法不会被骗：梯度下降、内点法在碗形地形上随便走，坡度为零处必是全局最低——起点无关；
  2. 可验证的停机条件：找到局部最优即可宣布胜利；
  3. 对偶理论成立：LP 的影子价格、对偶下界这些工具（第 9 节的主角）依赖凸性；
  4. 多项式复杂度：内点法对凸问题有理论保证。

非凸问题逐条失效：算法被困局部最优（解依赖初始点）、存在鞍点（梯度为零但既非最高也非最低的「山口」）、甚至判断「这是不是全局最优」本身就是 NP-hard。

5.4 快速判定表

判定手段凸非凸
一维图像只有一个谷底，弦在曲线上方多个谷底或有鼓包
二阶导 / Hessian处处 ≥ 0（半正定）某处 < 0
函数家族线性（既凸又凹）、x²、‖x‖、max/min of 凸函数sin、含负平方项的多项式、乘积 xy
可行域线性约束围出的多面体（LP 天然凸）曲约束、整数约束
两个容易忽略的细节

① 线性函数同时是凸和凹（弦和曲线重合）——LP 自动继承凸性的一切好处，这是它「可靠」的根源。② max 运算保凸但不保凹、且有折点不可导——配时里「阶段权重 = 成员流量的 max」这个折点，正是搭接问题「鸡生蛋」第一层的来源；max 凸但不可导，给优化添的是另一种麻烦。

6. 目标二次、约束线性：QP 解剖

6.1 多面体里扣一只碗

min  ½xTHx + cTx
s.t.  Ax ≤ b 目标可以弯（二次），边界必须直（线性）

几何意象：线性约束围出多面体（每条约束是一刀直切）；二次目标的等高线是一族同心椭圆；求解 = 在多面体内部找这只碗的最低点。三种典型结局：碗底在内部（无约束最优恰好可行）、碗底在外（最优解贴在某个平面上「顶着边界滚」）、碗被切到只剩边缘（解卡在角上，退化得像 LP）。

与 LP 的本质区别：LP 最优解必在顶点，QP 最优解可以停在一条棱的中段。

6.2 二次目标从哪来

线性说「每单位代价恒定」；二次项说代价随规模加速。天然来源：风险的方差本质（协方差是权重两两相乘的二次型）、误差的平方惩罚（最小二乘）、能量的物理定义（½mv²、I²R）、平滑性惩罚（相邻控制量变化的平方和）。

6.3 配时里的 QP：软约束微调

min  Σi (gi − ri·G)²
s.t.  gi ≥ 12,   Σgi = G 目标=偏离理想占比的平方和；约束=地板与守恒

与 LP 的分工：LP 回答「能否完全覆盖」（判定问题），QP 更适合「无法完美时如何最不坏」——偏离难免，那就按平方计费地最小化它。

7. LP 与 DP：两个维度的东西

维度线性规划 (LP)动态规划 (DP)
本质优化问题的类别（线性结构）求解算法的范式（多阶段递推）
变量连续通常是离散状态/决策
建模核心变量+线性目标+线性约束状态+阶段+转移方程
求解方式单纯形法、内点法手推递推式+记忆化
前提无（线性即凸）最优子结构 + 重叠子问题
典型问题生产计划、运输、资源分配最短路、背包、编辑距离、序列比对

它们不是并列关系——同一个问题可以「是 LP 且用 DP 解」。CS 本科只教 DP 当「算法设计技巧」（背包、LCS、Floyd），不讲它在运筹学里的出身（Bellman 的多阶段决策理论），更不把 LP/DP/凸性串成一张图。学过碎片，缺的是坐标系——本文就是补坐标系。

8. 学科归属：为什么大学没学过

这整套东西属于运筹学（Operations Research）/ 最优化（Optimization），往上追一层是应用数学。它二战后从军事运筹起家，与管理科学、工业工程、控制论、理论计算机科学交叉。

专业本科是否遇到课程名
数学（应用/计算数学）是，核心课最优化方法、运筹学
管理科学/工程管理是，核心课运筹学
工业工程是运筹学、生产调度
土木/交通工程常见运筹学（网络规划、交通分配）
计算机/软件工程基本没有只在算法课学 DP

两个补充原因：① 名字障眼法——课程叫「运筹学」不叫「优化」；② 年代感——现代凸优化叙事（Boyd《Convex Optimization》2004）大规模进国内课堂是 2010 年代且集中在研究生层，它真正「出圈」是被机器学习带火的（训练神经网络、SVM、正则化回归全是优化问题）。

9. 核心主线：建模 → 凸性 → 对偶下界 → 评分

这条链在回答一个问题：「我怎么知道我的算法给出的方案，是恰好最优，还是浪费了一堆？」四步各管一段，全程用二通西路南口走通。

9.1 第一步：LP 建模

见 2.3 节——把「安排绿灯」翻译成三要素：变量（各阶段时长）、约束（车流只认总量）、目标（总时长最短）。建模决定后面一切是否有意义：如果约束写错（比如把西直写成「两段各自 ≥ 48.5」），地板和高度就都在量一个错误的东西。

9.2 第二步：凸性保证

可行域：t₁ ≥ 58.8（竖线右侧）∩ t₂ ≥ 6.0（横线上方）∩ t₁+t₂ ≥ 48.5（斜线右上）= 朝右上张开的角——标准碗形。目标 t₁+t₂ 的等高线是斜率 −1 的平行线，往左下推。凸性的作用一句话：碗形可行域上「推不动了」就是「全宇宙最低」——不存在隔壁更深的坑。这是后面一切信任的地基。

9.3 第三步：对偶 = 下界（不解题，先掐底）

整条链最反直觉的一跳。换视角：

  • 正面（原问题）：构造一个具体方案让总时长尽量小 → 得到「我能做到」的数；
  • 反面（对偶问题）：不构造任何方案，只找一个理由证明「任何方案的总时长 ≥ 某个数」 → 得到「谁也逃不掉」的数。

找理由的技巧简单到离谱：把约束加起来。把第 1 条和第 3 条约束直接相加：

(t₁ ≥ 58.8) + (t₂ ≥ 6.0) ⇒  t₁ + t₂ ≥ 64.8 左边恰好是目标函数——一行方案都没写就掐住了它的底

人话版：东直 58.8 秒和西左 6.0 秒是两份互不相干的活儿（一个必须 S1 干、一个必须 S2 干），不管你多聪明地挪西直，这两份活儿本身就要占 64.8 秒。下界 = 无论如何逃不掉的工作量。

「对偶问题」就是把这招系统化：给每条约束配一个非负权重 λ，加权组合后左边若恰好覆盖目标函数，右边就得到一个下界；然后问「权重怎么选，挤出来的下界最大」。本例最优对偶解就是 λ₁=1, λ₂=0, λ₃=1（取约束 1 和 3，丢弃约束 2——西直那条约束因为可以被别人顺带满足，不构成额外的「逃不掉」）。

强对偶定理（靠凸性成立）

挤出来的最好下界 = 正面构造的最好方案——两条路殊途同归。这就是我们敢叫它 T_min（精确最低）而不只是「某个估计」的原因。非凸时两面之间有缝，下界会失效为「太松」——凸性是「对偶掐的底恰好能被正面达到」的前提。

9.4 第四步：用下界给算法评分

现在手上有两个数，来自两个相反的方向：

数来自含义二通西路南口
T_min反面（对偶）地板：任何方案都逃不掉的量64.8
W_algo正面（任何算法）你实际站的高度引擎等分 83.1 / 贪心 64.8

评分 = 高度 − 地板 = 该算法的浪费量。

引擎等分 W_eq = 83.1  →  浪费 (83.1−64.8)/64.8 = 28%   ← ÷stageCount 稀释的代价
贪心规则      = 64.8  →  浪费 0%                      ← 恰好踩在地板上，无需更好算法

对比 CHAIN 拓扑的坏案例（来广营北路与顺白路 plan1）：贪心 160.2，地板 140.4 → 浪费 14%。没有地板时只知道贪心输出了 160.2——好是坏无从谈起；有了地板，14% 直接告诉你「这个拓扑上贪心不够好，这里才值得上 LP 精确解」。贪心这类快速直觉算法天生不知道自己差多少，下界是唯一免费的裁判。

四步一句话版

把配时翻译成最短总时长+覆盖约束的 LP（建模）；这道题是碗形的，保证一次解对且正反两面严丝合缝（凸性）；不解题也能掐底——把约束加起来就证明总时长逃不过 64.8（对偶=下界=逃不掉的工作量）；于是任何快速算法的成绩单 = 它的输出离地板多远（评分）。

10. 这条主线如何改变了工程决策

工具就位后，我们对三个灰度目录 455 份回放 JSON 里的 357 个搭接 plan（220 个去重路口）做了全量三口径对比（W_eq 等分 / W_greedy 贪心 / T_min LP 下界）：

拓扑plan 数贪心达 LP 下界结论
SINGLE204100%闭式安全，无需 LP
CO-CORE4894%安全子集，可回收增益中位 9.8%
PURE-EXT5476%藏 92% gap 灾难案例（双翼汇入结构），缓行
CHAIN5169%顺序敏感，需显式定序或 LP

理论-实测闭环：三相位结构（CO-CORE 原型）的理论预测「轴权重虚高 7-33%」，实测中位 9.8%，正落在预测区间内。最终产出分层灰度路径：第一批 SINGLE+CO-CORE（顺序无关、达下界），第三批 CHAIN（配定序约定）。

方法论的胜利

没有这套数学工具时，只能对每个路口逐案争论「这个分配合理吗」；有了 LP 下界这个裁判，357 个 plan 的「谁最优、谁浪费、浪费多少」变成一行可复算的数字。这正是「学好数学的作用」最具体的形态：不是算得更快，而是把『我觉得』变成『我证明』。

12. 继续学习的路径

按性价比排序：

  1. Boyd《Convex Optimization》（斯坦福，配套公开课免费）——凸优化的事实标准教材，前几章覆盖凸集/凸函数/LP/QP/SOCP 全部概念，工程友好；
